The mechanic I did was the "Break" mechanic from Fire Emblem: Engage. 
The idea is when a unit attacks another unit at weapon triangle disadvantage (Swords beat Axe, Lances beat sword, Axes beat lance), they will become "broken" and will be 
unable to move. In this project I used Unity's input settings to attach the keyboard "E" to attack, and I used an interface and an interaction to set weapons to units and
check what weapon the enemy is attacked with. If the weapon is favorable and the armor box is not checked, the enemy will be broken, and a message will be displayed in the 
Debug menu. Video is in the RenderVideo folder.
